# Ghost Chat

Ghost Chat is an experimental privacy-focused chat application designed around direct, low-dependency communication and an offline-capable experience.

## Highlights
- Chat-oriented user interface
- Privacy-focused project direction
- Designed with offline/P2P capabilities in mind
- Mobile application packaging through Capacitor
- Web-based application architecture

## Tech Stack
- HTML/CSS/JavaScript
- Capacitor
- Node.js tooling

## Getting Started
Install the project dependencies with npm, then use the project's configured development/build scripts.

```bash
npm install
npm run build
```

Available scripts may change as development continues; check `package.json` for the current commands.

## Project Status
Experimental/development project. Security-sensitive features should be independently audited before production use.
